# Light / Dark Theme Switch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a System/Light/Dark theme switch (System by default, persisted) and make every screen readable in dark mode.

**Architecture:** Semantic colors become CSS variables in `src/index.css` (`:root` light, `.dark` dark) exposed to Tailwind v4 via `@theme inline`. A pure `src/lib/theme.ts` module parses/persists the preference and resolves it against the OS setting; a small hook applies the `dark` class to `<html>`, an inline script in `index.html` does the same before first paint, and a fixed corner button cycles the preference.

**Tech Stack:** React 19, TypeScript, Tailwind CSS v4, Vite, Vitest (node environment, injected storage like `src/lib/sequentialProgress.ts`).

**Spec:** `docs/superpowers/specs/2026-11-17-dark-mode-design.md`

## Global Constraints

- Preference values exactly `'system' | 'light' | 'dark'`; default and fallback `'system'`.
- localStorage key exactly `quiz-maker-theme`; every read/write wrapped in try/catch.
- Dark mode = `dark` class on `<html>` plus `style.colorScheme` `'dark'`/`'light'`; Tailwind variant `@custom-variant dark (&:where(.dark, .dark *));`.
- Light token values: `primary #1976d2`, `primary-dark #115293`, `correct #4caf50`, `correct-light #e8f5e9`, `incorrect #f44336`, `incorrect-light #ffebee`, `selected #2196f3`, `selected-light #e3f2fd`; other shadcn tokens use shadcn "neutral" light values.
- Dark values: background `#0f172a`, card `#1e293b`, primary (header) `#0d3b75`, softer green/red/blue for answer states (e.g. correct `#4ade80`/`#14361f`, incorrect `#f87171`/`#3f1d1d`, selected `#60a5fa`/`#1e3a5f`).
- Switch: round button fixed bottom-right on every screen, cycling 🖥️ System → ☀️ Light → 🌙 Dark, `aria-label` and `title` naming the current choice.
- Work in worktree branch `feat/dark-mode`; `npm run lint -- --max-warnings=0` clean before every commit; commits via `git-smart-commit` with the `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` trailer.
- Out of scope: removing `tailwind.config.js`, other color themes, localisation.

## Review Focus

- localStorage throws (private window / blocked storage) → app still loads, follows system, switch still works for the session.
- Stored value is garbage (`"blue"`, `""`) → treated as `system`.
- In System mode, OS switches light↔dark while the app is open → theme follows without reload; in Light/Dark mode it does not.
- On a phone-width screen the corner button covers a bottom control (Submit/Next in `QuestionCard`, navigator) → page needs bottom padding so nothing is hidden.
- Dark mode text contrast: `text-muted-foreground` and answer text on `correct-light`/`incorrect-light` backgrounds stay readable.
